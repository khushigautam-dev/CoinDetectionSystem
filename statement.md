# Project Statement

## Project Title

Coin Detection and Counting System Using Computer Vision

## Problem Statement

Counting coins manually from an image can take time and may lead to mistakes. A simple automated system can use Computer Vision to identify coins and calculate their total count.

## Scope

The project focuses on detecting and counting clearly visible coins in an image. The current version is designed for images where coins are sufficiently separated from each other.

The project does not currently identify the denomination or monetary value of individual coins.

## Target Users

- Students learning Computer Vision
- Educational institutions
- Users who need a simple automated coin-counting tool
- Beginners interested in image processing applications

## High-Level Features

- Upload a coin image
- Preprocess the image
- Detect coin objects
- Count detected coins
- Display the detection result
- Save the output image
- Simple graphical user interface

## Expected Outcome

The system should take a coin image as input, detect the visible coins, display the total number of detected coins, and save the processed result.
